# Yadamreddy Meena Sai — Personal Portfolio

A responsive personal portfolio website showcasing my education, technical skills, projects, certifications, internship experience, and contact information.

## 🌐 About the Project

This portfolio is designed to present my profile as a **Computer Science & AI/ML student** and aspiring Software Engineer.

The website provides a clean, responsive interface with sections for:

* About Me
* Education
* Technical Skills
* Projects
* Certifications
* Internship
* Contact

It also includes interactive features such as dark/light mode, project filtering, scroll animations, mobile navigation, form validation, and a back-to-top button.

## ✨ Features

* **Responsive Design** — Works on desktop, tablet, and mobile devices.
* **Dark/Light Mode** — Users can switch between light and dark themes.
* **Sticky Navigation** — Navigation remains accessible while scrolling.
* **Active Navigation** — Automatically highlights the current section.
* **Mobile Hamburger Menu** — Provides a mobile-friendly navigation experience.
* **Project Filtering** — Projects can be filtered by Java and Web categories.
* **Scroll Reveal Animation** — Sections appear smoothly while scrolling.
* **Contact Form Validation** — Validates name, email, subject, and message fields.
* **Back-to-Top Button** — Quickly returns to the top of the page.
* **Resume Download** — Allows visitors to download the resume.
* **GitHub & LinkedIn Links** — Provides direct access to professional profiles.
* **Accessibility Support** — Includes labels, focus states, ARIA attributes, and reduced-motion support.

## ⚙️ How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/meenasai13/personal-portfolio.git
```

### Step 2: Open the Project

Open the project folder in **Visual Studio Code**.

### Step 3: Run the Website

You can open `index.html` directly in a browser.

For a better development experience, use the **Live Server** extension in VS Code.

1. Open `index.html`
2. Right-click the file
3. Select **Open with Live Server**

The portfolio will open in your browser.

## 📱 Responsive Design

The website is designed to adapt to different screen sizes:

* Desktop
* Laptop
* Tablet
* Mobile

CSS media queries are used to modify the navigation, project layout, contact section, spacing, and other components for smaller screens.

## 🌙 Dark/Light Mode

The theme toggle allows visitors to switch between light and dark modes.

The selected theme is stored using:

```javascript
localStorage
```

This allows the website to remember the user's theme preference when they revisit the site.
